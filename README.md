# Learning Notes

Self-contained deep-dive courses on Go and distributed systems. Each course is a single
HTML file with a sidebar, table of contents and reading-progress bar — no build step,
no dependencies. Open it in a browser or print it to PDF.

**Read online:** https://maksymus.github.io/learning-notes/

| Course | Chapters | Topics |
| --- | --- | --- |
| [Deep Go](deep-go.html) | 6 | Data types, slices, strings, maps, functions, structs, interfaces, errors, generics, reflection, memory, GC, scheduler |
| [Concurrency in Go](concurrency-go.html) | 10 | Goroutines, the scheduler, sync primitives, channel internals, channel patterns, contexts, memory barriers, lock-free algorithms |
| [Resiliency Patterns](resiliency-patterns.html) | 6 | Fault tolerance principles, transient failures, load control, async communication, caching, failure detection |
